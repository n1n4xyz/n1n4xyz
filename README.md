## Selected work

- [creator-signature](https://github.com/n1n4xyz/creator-signature) - proof of provenance for the open web. A verified human signs content under their on-chain identity, and any copy anywhere can be checked against that signature. Built at ETHGlobal Lisbon 2026. TypeScript.
- [sello](https://github.com/n1n4xyz/sello) - portable loyalty for independent shops. A merchant signs a receipt, the customer's phone reads it with a local model, and only the score is published. No purchase history leaves the device. JavaScript.
- [atomicyield](https://github.com/n1n4xyz/atomicyield) - fitness staking on Solana with x402 agentic payments. The oracle agent pays per verification call in USDC and holds no pre-provisioned API keys. Rust.
- [HealthArkiv](https://github.com/n1n4xyz/HealthArkiv) - user-owned health tracking on Arkiv, Ethereum's data layer. Symptom and biomarker logs are encrypted with a key only the wallet controls, with time-limited access for clinicians. TypeScript.
- [ethical-multi-agent-orchestrator](https://github.com/n1n4xyz/ethical-multi-agent-orchestrator) - three specialised agents over separate Azure data stores, with a domain-specific ethical check that runs against the data behind each answer rather than as a manual step. Python.
- [applied-industry-system-design](https://github.com/n1n4xyz/applied-industry-system-design) - EACIS, a career intelligence system for the European AI job market. RAG over job postings, archetype matching and a ReAct agent, designed against the EU AI Act. Jupyter.
